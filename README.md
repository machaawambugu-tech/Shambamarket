# 🌾 ShambaMarket
### Connecting Kenyan Farmers with Buyers

## 📌 About the Project
ShambaMarket is a web-based agricultural marketplace designed to connect farmers directly with potential buyers. It allows farmers to list their produce, set prices, and share their locations so buyers can easily find available agricultural products.

The project aims to improve access to market information and make it easier for farmers and buyers to compare produce prices.

## 🎯 Problem Statement
Some Kenyan farmers face challenges accessing reliable market information, finding buyers, and comparing prices for their produce. These challenges can make it difficult to identify suitable markets.

ShambaMarket proposes a digital solution that brings produce listings and price information together in one platform.

## 💡 Objectives
- Connect farmers with potential buyers.
- Allow farmers to list their agricultural produce.
- Display produce quantities, prices, and locations.
- Help buyers compare available products.
- Explore agricultural price trends as more data becomes available.

## ✨ Features
- 🌽 **Produce Listings:** Farmers can add produce for sale.
- 💰 **Price Display:** Shows the asking price per kilogram in Kenyan shillings.
- 📍 **Location Information:** Displays where the produce is available.
- 🛒 **Marketplace:** Buyers can browse listed agricultural products.
- 🌙 **Dark Mode:** Allows users to switch between light and dark themes.
- 📱 **Responsive Design:** Designed to work on different screen sizes.

## 🛠️ Technologies Used
- **HTML** — webpage structure.
- **CSS** — styling, layout, and themes.
- **JavaScript** — adding produce and updating marketplace listings.

## 🚀 How to Run the Project
1. Download or clone this project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter the farmer's name, produce name, quantity, price, and location.
5. Click **Add Produce** to display the listing.

No server is required for the basic prototype.
